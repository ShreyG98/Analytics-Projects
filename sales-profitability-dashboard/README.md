# Sales & Profitability Dashboard

## Overview

An interactive Excel dashboard built to analyse sales performance and profitability across products, categories, regions, and months.

The dashboard uses PivotTables, PivotCharts, KPI cards, and interactive slicers to turn raw sales data into a simple business-performance overview.

## Tools Used

- Microsoft Excel
- PivotTables
- PivotCharts
- Slicers
- Excel formulas

## Dashboard Features

- Total Revenue
- Total Profit
- Profit Margin
- Units Sold
- Monthly Revenue Trend
- Profit by Category
- Regional Performance
- Product Performance
- Interactive Region and Category filters

## Dataset

The dataset contains 150 sales transactions covering:

- 10 products
- 3 categories
- 4 regions
- January–September 2026

The dataset includes information such as units sold, selling price, cost, revenue, profit, and profit margin.

## Project Structure

- `sales_profitability_dashboard.xlsx` — completed interactive dashboard
- `sales_profitability_dataset.xlsx` — original dataset
- `dashboard_screenshot.png` — preview of the dashboard
